# Kasau Vulnerability Scanner v2.0

![Kasau Scanner Banner](assets/banner.png)

An advanced vulnerability scanner for infrastructure and web applications with comprehensive reporting.

## Features

- **Multi-threaded Scanning**: Fast parallel execution
- **Comprehensive Checks**:
  - Port scanning with service detection
  - Web vulnerability checks (SQLi, XSS, sensitive files)
  - System misconfiguration detection
- **Detailed Reporting**: JSON reports with timestamps and metrics
- **Logging**: Comprehensive logging for audit trails
- **Modular Design**: Easy to extend with new checks
